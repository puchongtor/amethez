## สิ่งที่ล็อกแล้ว (2026-08-09)

### ภาษา
- ชื่อหิน: **ไทย + EN**
- คำเฉพาะคงศัพท์มาตรฐาน (Chakra, Zodiac, Mohs, Element ฯลฯ)
- เนื้อหาสั้นบนการ์ด: ภาษาไทย

### โหลด / แบรนด์
- **ฟรีโหลดเต็ม** ไม่ตัดคุณภาพ
- ทุกใบมี **แบนด์ Amethez** = โลโก้ผลึก + ชื่อ AMETHEZ + `amethez.com`
- หน้าการ์ด = **แบรนด์ Amethez อย่างเดียว** (ไม่ใส่ Atlas / เมษา / อวาตาร์)

### สไตล์ลายเซ็น (รวมทุกแกน “ว้าว”)
ไม่ใช่เทมเพลต Etsy ทั่วไป — ใบเดียวต้องมีครบ:

| ชั้น | รายละเอียด |
|------|------------|
| ซีรีส์สะสม | `AMETHEZ STONE CARD · ### / 300` |
| รูปบรรยากาศ | หินบนพื้นมีแสง/โทนสีหิน — ไม่ใช่ cutout ขาวล้วนอย่างเดียว |
| ชื่อ | ไทยใหญ่ + EN ตัวเล็ก caps |
| คำติดหู | ประโยคไทย 1 บรรทัด ใน「」 — ต้องอ่านแล้วรู้ความหมายทันที เช่น อเมทิสต์ 「สำเร็จจากสมาธิและปัญญา」 |
| Science × Soul | สองกล่องคู่: สูตร/Mohs/แหล่ง · จักระ/ราศี/ธาตุ |
| ใช้วันนี้ | ทิศวาง · วันเหมาะ · สีประจำ |
| หินคู่ | เข้ากัน + ระวัง (สั้น) |
| QR | → `amethez.com/stones/{slug}` |
| แบนด์ล่าง | โลโก้ + AMETHEZ + tagline + URL |

## จุดวางบนเว็บ (แผน)

**การ์ดข้อมูล A**
1. หน้าเดียว `/cards/` — กริด + โหลดฟรี + CTA ขายชุด / รับออกแบบ
2. ไฟล์ `/images/cards/stones/{slug}-card.jpg`
3. ทุกหน้า `/stones/[ชื่อ].html` — `og:image` ชี้ไฟล์การ์ด (ทีหลัง)
4. QR บนการ์ด → หน้าหินนั้น

**รายได้ 3 ชั้น**
- ฟรีโหลด (SEO รูป + แบรนด์)
- ขายชุดพิมพ์ / PDF
- รับออกแบบให้ร้านหิน (สลับโลโก้ร้าน)
