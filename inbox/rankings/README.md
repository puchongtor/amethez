# Inbox — ซีรีส์เรื่องราวจากโลกของหินและคริสตัล

วางไฟล์บทความที่นี่ ระบบจะสุ่มดึงไปสร้างเป็น **Draft** ในชุด ranking

## ไฟล์ที่รองรับ
- `.md` หรือ `.txt` ตามฟอร์มบทความ (แนะนำ)
- `.pdf` — ต้องมี `pdftotext` ในเครื่อง หรือวางไฟล์ `.md` ชื่อเดียวกันไว้คู่กัน

อัปโหลด PDF ตรงใน Admin ก็ได้ (แท็บจัดอันดับหินคริสตัล) ไม่ต้องพึ่งโฟลเดอร์นี้

## วิธีใช้
1. ใส่ไฟล์บทความในโฟลเดอร์นี้ (วันละประมาณ 5 เรื่อง)
2. รัน:

```bash
node scripts/ingest-ranking-series.js
```

3. ไฟล์ที่ประมวลผลแล้วจะถูกย้ายไป `processed/`
4. เปิด Admin → จัดอันดับหินคริสตัล
   - พรีวิวรูปที่เจนจาก Google API
   - ถ้าไม่โดน กดเจนใหม่หรืออัปโหลดแทน
   - กดยืนยัน → ระบบจัดคิวโพสต์วันละ 2 ตอน (08:00 และ 20:00)

## ฟอร์มบทความ
ใช้โครงเดียวกับตอนอุกกาบาต: หัวข้อหลัก, 5 เรื่องเด่น, บทสรุป, SEO, แหล่งอ้างอิง, IMAGE PROMPT 1–5, HERO IMAGE PROMPT
